3 · Dataset

The dataset comes from the original NL-RX work. Each description was paraphrased by a crowd worker from a templated sentence, which makes the language realistic and noisy. Only one pair was a duplicate. The important number is 94.5 percent: nearly all test regexes are new combinations the model has never seen, so the test set measures generalisation, not memorisation. The vocabularies are built on the training split only.
