Why it fails

  • “not X or Y” has two readings, and the description rarely says which
  • Noisy paraphrases, with typos and odd wording
  • Dataset convention: ~(dog) matches any line that is not exactly “dog”
  • 94.5% of test regexes are new combinations

14 · Error analysis

Of 999 test examples, 453 are exact matches and another 197 behave like the reference while being written differently. Only one output is not a valid regex, so the decoder has learned the syntax. The 348 valid-but-wrong outputs are where the problem is: negation and word boundaries are the weakest cases, because the model has to get grouping and scope right, which a fixed set of recurrent states learns poorly. Some of the errors are also the dataset’s fault: descriptions are noisy and several regexes can be valid readings of the same sentence.
