7 · Architecture

This is the baseline architecture, written with PyTorch building blocks: embeddings, LSTM layers and linear layers. The encoder reads the description and produces a final hidden and cell state. A small bridge, a linear layer followed by tanh, turns that into the decoder’s starting state. The decoder then generates one regex token at a time, feeding back its previous token, and stops when it predicts the end token or reaches 60 tokens. In the baseline, that one final state is the only channel from input to output, which is the weakness attention fixes.
