Why a new dataset

In the standard benchmark, English and regex can disagree

NL-RX description

lines with the string ‘dog’ at least 2 times

NL-RX label

.*(dog){2,}.*

dogdog

accepted: two copies side by side

dog and dog

rejected, although it contains ‘dog’ twice

The model learned this label faithfully, so a correct output looked wrong to a human reader. The templated version of the dataset (NL-RX-Synth) has the same convention. Our first model scored 45.3% exact match on this data.

3 · Why a new dataset

We started with the standard dataset, NL-RX, and got 45 percent exact match. Looking at the outputs we found that some labels do not mean what the English says. Here the description says the string dog at least two times, but the label only accepts two adjacent copies, so a line like dog and dog is rejected. The model reproduced the label exactly, which is correct by the benchmark and wrong for a person. Rather than train on labels we could not trust, we built a dataset where every label is checked.
