5 · Dataset

The generator knows thirteen kinds of condition, such as contains, starts with, at least N times, N times in a row, before, immediately followed by, length and made only of, and combines them with not, and, or. Sentences come from over two hundred phrasing templates. We split by regex, so the test regexes are new to the model. Because the in-distribution test could be too easy, we built two harder tests: one with sentence patterns that never appear in training, and fifty descriptions written by hand. For the handwritten set most regexes are simple, so it tests wording rather than new structure.
