How to write a description
  • Put literal text in quotes: 'cat', "2024", 'ice cream'. Any word works: the model sees it as a slot and copies it into the regex.
  • It understands: contains, starts with, ends with, is exactly, at least / fewer than N times, N times in a row, before / immediately followed by, length (at least, at most, exactly), made only of, and the words not, and, or.
  • Character types: digit (number), letter, capital (uppercase), lowercase, vowel, space.
  • Regexes match the whole line. The dialect adds & (and) and ~ (not), which ordinary regex engines do not have, so the tester below uses our own matcher.
  • It is a small model (1.4M parameters) trained only on our generated sentences: wording far from them, such as “kick off with”, is where it fails.

How this website works

  • No server. The two trained models (1.38M and 0.96M parameters) are downloaded once and run in your browser, in plain JavaScript written for this project. Nothing you type leaves your computer.
  • Same answers as PyTorch. The JavaScript inference was checked against the original PyTorch models on all 3,434 test sentences: identical output for every one, for both models.
  • Our own regex matcher. The regex dialect has intersection (&) and complement (~), so a matcher was written for it and checked against the Python one on about 3 million (regex, string) pairs.
  • Model. Embedding (128), one LSTM layer (256), a linear and tanh bridge, then an LSTM decoder with additive attention over the input words. Greedy decoding, stopping at the end token. Quoted literals become slots (__w0__, __w1__) and are copied back after decoding.
  • Data. VeriRegex, built for this project because the standard NL-RX labels sometimes contradict their English. Every pair comes from one meaning tree and is checked by an independent Python definition on about 300 strings. 37,586 training pairs; test sets of new regexes, new phrasings and handwritten descriptions.

pip install torch matplotlib        # the dataset is already inside the zip
python src/train.py --name lstm_attn --attention      # train
python src/evaluate.py results/lstm_attn --beam 5     # evaluate
